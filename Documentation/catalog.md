# كتالوج المشاريع

يحتوي `ArduinoProjects/<id>/<id>.ino` على ملف Arduino لكل مشروع. تجمع أداة Python تعريفات المشاريع في `Tools/catalog_a.py` و`Tools/catalog_b.py` وسجل القطع المشترك في `Tools/catalog_common.py`. تُنشئ الأداة كتالوج Unity في `Assets/Resources/MechaVision/catalog.json` ونسخًا مطابقة من الرسومات في مجلد `Sketches`. تستخدم النسخ امتداد `.txt` كي يستوردها Unity كملفات TextAsset. يصدر التطبيق الكود باسم `<id>.ino`.

```sh
python3 -m pip install -r Tools/requirements.txt
python3 Tools/build_catalog.py
python3 Tools/build_catalog.py --check
python3 -m unittest discover -s Tools -p 'test_*.py'
```

أعد توليد الكتالوج بعد تعديل تعريف أو ملف Arduino. يفحص الخيار `--check` توافق الملفات المولدة مع مصادرها. كل قطعة لها معرّف ثابت وحجم بالمتر وأطراف محلية. كل وصلة تشير إلى طرفين بالصيغة `instance_id.PIN` وإلى خطوة واحدة تُظهرها. تظهر القطع الصغيرة التي تدعم فتحات اللوح فوق اللوح، وتستخدم القطع الخارجية صفوفًا مجاورة. تمثل إحداثيات القطع الخارجية وأطرافها أبعادًا تعليمية تقريبية. قارن أسماء الأطراف وترتيبها مع إصدار وحدتك الفعلي قبل التوصيل.

يبدأ نظام الإحداثيات في مركز السطح العلوي للوح 830 نقطة، ويمتد المحور X على الطول. المسافة بين الثقوب 2.54 مم. عند توصيل وصلة بقطعة مغروسة في اللوح، استخدم فتحة شاغرة في الشريط الموصل نفسه بدل إدخال السلك ورِجل القطعة في الثقب نفسه. الفجوة الوسطى تفصل المجموعتين.

تسجل قاعدة البيانات اسم المكتبة وإصدارًا مرجعيًا محددًا حين يلزم تثبيتها. تحققت الأداة من هيكل البيانات وأسماء الأطراف وانتظام الخطوات ومواضع الثقوب وبعض أخطاء التوصيل الواضحة. يتحقق فحص الكود من تعيينات GPIO البسيطة ومن تعليقات `// @pin` التي تسجل المنافذ المستعملة عبر المصفوفات والمكتبات. يتطلب التجميع على Arduino Uno تشغيل Arduino CLI مع AVR core والمكتبات المشار إليها. يتطلب التحقق الكهربائي وقياس الأداء مراجعة بشرية وتجربة فعلية. تظهر كل المشاريع بصفتها مسودات تعليمية تحتاج مراجعة المعلّم قبل التركيب.

تضم سجلات المصادر تاريخ الوصول للرابط عندما أمكن فتحه من البيئة السحابية. في فحص 19 نوفمبر 2026 استجابت 15 وصلة فريدة من GitHub وRaw GitHub، وحجب وكيل الشبكة 46 وصلة خارج تلك النطاقات. يدل تاريخ الوصول على إمكان فتح المصدر. تبقى مطابقة مواصفات القطعة والدائرة جزءًا من المراجعة الكهربائية.

استُبدلت أمثلة كشف اللهب والغاز بمفتاح تصفيق ومقياس ارتفاع بارومتري لتفادي استخدام لهب أو غاز أثناء الدرس. واستُبدل نموذج الستارة الضوئية بمؤشّر ميل بتسارع ثلاثي المحاور لتنويع المحتوى، لأن مشروع متتبّع الشمس يغطّي بالفعل تجربة الحساس الضوئي مع محرّك السيرفو.
