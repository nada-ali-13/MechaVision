# اختبار التتبّع على Galaxy S22

سجّل رقم بناء التطبيق، وطراز الهاتف وإصدار Android وGoogle Play Services for AR، ومقاس المرجع المطبوع المقاس بالمسطرة، وقيم معايرة البورد، والإضاءة والمسافة بين الهاتف والبورد. ثبّت البورد والمرجع على حامل صلب واحد وابدأ بمشهد TrackingProof.

| الحالة | الإجراء | النتيجة التي تُسجّل |
| --- | --- | --- |
| الالتقاط | وجّه الكاميرا إلى المرجع بالكامل | زمن الظهور والفرق بين كل طرف وثقبه المقصود بالملليمتر |
| حركة الكاميرا | حرّك الكاميرا والبورد ساكن | أقصى انحراف واستقرار العرض في زوايا مختلفة |
| حركة البورد | أبقِ الكاميرا ثابتة وانقل الحامل يمينًا ويسارًا | هل تتبع جميع العناصر الحركة؟ سجّل التأخير والانحراف |
| دوران البورد | دوّر الحامل ببطء ثم أعده | أقصى انحراف وهل تدور المسارات مع البورد |
| فقدان المرجع | غطِّ المرجع وحرّك الحامل ثم اكشفه | زمن اختفاء العناصر وإعادة ظهورها عند الموضع الجديد |
| العودة للتطبيق | أرسل التطبيق للخلفية ثم عد إليه | إخفاء العناصر حتى عودة التتبّع المباشر |
| تغيير المشروع | افتح مشروعًا آخر وجرّب عدة خطوات | ظهور المكوّنات والأسلاك المناسبة وبقاء التتبّع |
| الوصول للكود | افصل الإنترنت وابحث وافتح الكود واحفظه أو شاركه | وجود ملف `.ino` قابل للقراءة باللغة الأصلية |

حالة الاختبارات على الجهاز في التسليم السحابي: لم تُنفّذ.
